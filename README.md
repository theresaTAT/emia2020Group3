# UST Commute prototype

Clickable prototype of a commute app for HKUST students: route planner with the HKUST shuttle, shared taxi meetup groups, and door-to-door pickup. All data is mock data.

`index.html` is a single self-contained page with no external requests. On phones it opens full screen like an app; on desktop it shows a phone frame with design notes.

## Deploy
Static site, no build step. On Netlify: import this repo, leave the build command empty, publish directory `.`.
